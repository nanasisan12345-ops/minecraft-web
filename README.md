# Minecraft Web

## 開発 / GitHub Pages 公開

このプロジェクトは Vite + Three.js 構成に移行しました。編集は `src/game/parts/*.js` と `src/styles.css` で行い、`src/game.generated.js` は自動生成されるため直接編集しません。

```powershell
npm install
npm run dev
```

ローカル確認: `http://127.0.0.1:5173/`

Pages向けの本番ビルド:

```powershell
npm run build
```

`dist/` がGitHub Pagesへアップロードされる成果物です。`.github/workflows/deploy-pages.yml` を追加済みなので、GitHub側で Pages の Source を「GitHub Actions」にしておけば、`main` へ push したときに自動でビルド/公開されます。`music/` のmp3はビルド時に `dist/music/` へコピーされます。

主な編集場所:

- `src/game/parts/32-world-window.js`: 地形生成範囲、チャンク/窓更新
- `src/game/parts/34-mesh-rebuild.js`: ブロックメッシュ再構築
- `src/game/parts/82-weather-and-loop.js`: 天候とメインループ
- `src/game/parts/60-rave-venues.js`: 音楽会場
- `src/game/parts/70-music.js`: mp3 BGM
- `src/styles.css`: UI表示

## マップ生成

地形生成は `src/game/parts/32-world-window.js` にまとまっています。現在は座標シードから以下を自動生成します。

- バイオーム: 草原 / 森林 / 砂漠 / 高地 / 雪原 / 沼地 / ジャングル / 火山
- バイオーム別の高さ、表層ブロック、木の密度、草花の密度
- 高地/雪原は探索しやすいよう、高さ差を抑えた山地として生成
- 🗻 ランドマーク「富士山」: 通常の高さ上限を超える雪冠の大円錐火山。森の裾野・火山岩の中腹・雪の山頂・碗状の火口を持つ。スポーンから少し離れた位置に1つ生成。`F11` で移動
- ジャングルは木が密で高く、沼地は水辺が多く、火山は高所に溶岩クレーター

最初に画面をクリックするとゲームが開始します。
スポーン地点の周辺は、音楽会場をテストしやすいように木や草花のない平地になっています。
地形確認用に `F3` でデバッグ飛行を切り替えられます。飛行中は `Space` で上昇、`Shift` で下降、`Ctrl` で高速移動できます。`0` は鳥居、水上鳥居、千本鳥居風参道、大きな寺、五重塔、茶屋、天守閣、大仏、棚田、東京タワー風タワー、灯台、神社境内などの和風建築を順送りで探して移動します。`F4` は近くの洞窟入口を探して移動します。
通常移動では1ブロック程度の段差を自動で上がれるため、低い起伏は歩いて越えられます。

## サバイバル

Minecraft風のサバイバルゲームとして遊べます。ゲームループは「木を切る → 作業台 → 道具 → 採掘 → かまどで精錬 → より良い装備 → 夜を越える → 拠点を作る → 探索を広げる」です。画面右上に「次の目標」が常に表示され、達成すると通知が出ます（全19段階、達成状況は保存されます）。

### インベントリとクラフト

- ホットバー9枠＋メインインベントリ27枠のスロット式。スタック上限は64（道具・武器はスタック不可）
- `E` / `Tab` でインベントリを開くと **2x2クラフト** ができ、設置した作業台を右クリックすると **3x3クラフト** ができます
- スロットはクリックで持つ/置く、右クリックで半分取る/1個ずつ置く、Shift+クリックで一括移動
- 主なレシピ: 丸太→板材、板材→棒/作業台、丸石8→かまど、板材8→チェスト、石炭+棒→松明、繊維4→布、布3+板材3→ベッド、小麦3→パン、各素材+棒→ツルハシ/斧/シャベル/剣（木/石/鉄/ダイヤ）

### 採掘と道具

- ブロックごとに硬さと適正ツールがあり、適正ツールを持つと速く掘れます
- 石系はツルハシが必要。**鉄鉱石は石のツルハシ以上、金/ダイヤ鉱石は鉄のツルハシ以上**でないとドロップしません
- 石を掘ると丸石になり、かまどで焼くと石に戻ります
- 道具・武器には耐久値があり（スロットに耐久バー表示）、0になると壊れます

### かまど

設置したかまどを右クリックすると、材料/燃料/完成の3スロットと精錬・燃料バーのUIが開きます。中身は座標ごとに保存され、閉じている間も精錬が進みます。精錬: 粗鉄→鉄インゴット、粗金→金インゴット、砂→ガラス、丸石→石、生肉→焼いた肉、丸太→石炭。燃料: 石炭/丸太/板材/棒。

### 体力・空腹・死亡

- HP20・空腹20。空腹が満ちていると自然回復し、0になると飢餓ダメージ
- 落下・溶岩・サボテン・敵の攻撃でダメージ（被弾後は短い無敵時間）
- 食料（リンゴ/ベリー/パン/生肉/焼いた肉など）はホットバーで選んで右クリックで食べます
- HPが0になると死亡画面が出て、リスポーンボタンで復活（ベッドで寝ているとベッドが復活地点）
- **死ぬと持ち物は死んだ場所に散らばります**（約5分で消える。死亡画面に座標を表示）。大事なものはチェストへ

### ドロップアイテム

壊したブロックや倒した敵のドロップは、その場に実体として落ちます。近づくと吸い寄せられて自動で拾います（インベントリが満杯だと残る）。落ちたアイテムは約90秒で消え、リロードしても保存されています。

### 弓と防具

- **弓**（棒3+繊維3）と**矢**（丸石+棒+繊維→4本）をクラフトすると、右クリックで遠距離攻撃（ダメージ5）ができます
- **防具**は布の服（-12%）/鉄の鎧（-30%）/ダイヤの鎧（-42%）の3種。インベントリ画面の防具スロットに装備すると被ダメージが減ります（被弾のたびに耐久消費）

### 敵MOBと戦闘

- **ゾンビ**: 夜の地上に湧いて追いかけてくる。昼になると日なたで燃える。倒すと腐った肉
- **スケルトン**: 夜の地上や洞窟に湧き、距離を取って矢を撃ってくる。倒すと骨
- **スライム**: 洞窟・地下・沼地に湧き、跳ねながら体当たり。倒すとスライム玉
- 左クリックで攻撃。武器で威力が変わり（素手1/木の剣3/石4/鉄6/ダイヤ8）、ノックバックあり
- 敵が湧くのは**夜の地上**と、**頭上がブロックで塞がって空が見えない暗い場所（洞窟など）**だけです。峡谷の底のような空が見える場所には昼間は湧きません。ゾンビは昼に空の下へ出ると燃えます（日陰では燃えません）
- 地上は最大20体・地下は最大10体、プレイヤーから16ブロック以内には湧かず、80ブロック以上離れると消えます
- **松明などの明かりの周囲8ブロックには敵が湧きません**。拠点や洞窟の安全確保に重要です
- **音楽会場を出している間は敵が湧かず、出ていた敵も消えます**（安心してパーティーできます）
- 動物を攻撃すると生肉（羊は布も）が手に入ります

### 拠点づくり

- チェスト（27枠）にアイテムを保管でき、中身は座標ごとに保存されます
- ベッドを置いて夜に右クリックすると朝までスキップし、リスポーン地点になります（近くに敵がいると眠れません）
- 地下遺跡・廃坑・村などのチェストには探索報酬が入っており、空けたあとは普通の収納として使えます

### 村人取引

村人を右クリックすると役割ごとの取引ができます: 農民（食料）、鍛冶屋（鉄の道具・武器）、商人（金/ダイヤ→レア建材）、聖職者（明かり）、見張り（松明・石の剣）、司書（地下遺跡・廃坑の場所ヒント）、牧場係（布・肉）、旅人（村・洞窟・見どころの場所ヒント）。

### セーブ

プレイヤー位置/HP/空腹/インベントリ/時間/かまど/チェスト/ベッドのリスポーン地点/進捗/取引回数は `mc_save_<シード>` に、ブロックの設置/破壊は `mc_edits_<シード>` に自動保存されます（10秒ごと＋操作時）。リロードしても続きから遊べます。

## 音楽会場モード

`R/T/Y/U/I/O/P/[` で、プレイヤーの足元付近に音楽会場を出現させます
（数字キーはサバイバルのホットバー選択に使うため、会場キーは英字になりました）。
同じキーをもう一度押すと、その会場を消せます。

| キー | 会場 | 音楽の方向性 | 見た目の方向性 |
|---|---|---|---|
| `R` | `WAREHOUSE RAVE` | ダークテクノ。サチュレーションの効いた重いキック、オフビートでうねるサブベース、暗いスタブ、深いリバーブ | 暗い倉庫、トラス、スピーカー、青紫系ライト |
| `T` | `EUROBEAT ROAD` | ユーロビート。速いBPM、16分のオクターブ走りベース、きらびやかなスーパーソウのリード（ディレイ） | 道路ステージ、赤黄ネオン、ゲート状ライト |
| `Y` | `TRANCE DOME` | アップリフティングトランス。オフビートのゲートベース、巨大なスーパーソウのパッド、アルペジオ（リバーブ＋ディレイ深め） | 半透明ドーム、同心円リング、青紫のクリスタル |
| `U` | `DANCE FLOOR` | ディスコハウス。ファンキーなシンコペーションベース、7thコードのスタブ、スラップディレイ | 白黒チェック床、ミラーボール、金色の柱 |
| `I` | `FUTURE BASS SKY` | フューチャーベース。明るいコード、声ネタ風シンセ、サブドロップ、ビルドアップのライザー | 浮遊島、菱形フロア、ピンクとシアンのリング |
| `O` | `DRUM BASS TUNNEL` | ドラムンベース。高速ブレイクビーツ、ワブルベース、強いサブ、暗いフィル | 緑発光のトンネル、スピーカー壁、細いレーザー |
| `P` | `LOFI HOUSE LOUNGE` | ローファイハウス。遅めのBPM、柔らかいコード、ゆるいキック、空気感のあるノイズ | 月明かり、ソファ、丸いラウンジ床、控えめな照明 |
| `[` | `DUBSTEP LAB` | ダブステップ。ハーフタイムのドラム、うねるグロウルベース、金属的なスクリーチ | 暗い実験室、強いマゼンタ照明、細かいレーザー |

会場BGMは `music/` に置いた mp3 を再生します。mp3 が無い、または再生に失敗した会場は無音のままビジュアルと拍同期だけ動きます。
著作権付き楽曲は入れていません。

画面左下には会場キーの小さな一覧が表示され、現在出ている会場は光って分かるようになっています。
この一覧はクリック/タップでも会場を切り替えられます。
左上のステータスには、会場名、曲番号、BPM、NPCの入場状況も表示されます。

サビやドロップでは、観客NPCが波のようにジャンプして手を上げ、外側へ広がります。
歓声のような光粒子も円形に飛びます。
会場内で `Z/X/C/V` を押すとプレイヤーダンスになり、近くのNPCがこちらを向いて真似します。
DJ操作やダンス、サビの盛り上がりで右上の `CROWD HYPE` ゲージが上がります。
満タンになると `HYPE MAX` になり、観客リアクション、照明、クラッシュ音、上空の花火がさらに派手になります。
`K` のクラッシュ操作でも小さめの花火が打ち上がります。
DJ操作やダンスを続けると `GROOVE` コンボが伸び、ゲージ上昇量が少し増えます。
操作時には画面フラッシュ、GOOD系のポップ表示、床を走る光のショックウェーブも出ます。
各会場には拍同期ギミックがあり、Future Bassでは浮遊島、DNBではトンネルの光、Lofiでは月やランプがふわっと動きます。
床タイル、ゲート、音ブロック風の小さなブロックもキックやサビに合わせて伸びたり光ったりします。
会場を出した後に `Q/E/J/K/L` を押すと、曲送り、フィルター、クラッシュ、ループロールをDJのように操作できます。

各会場は、コンプレッサー／コンボリューションリバーブ／テンポ同期ディレイの FX バスと、
キックに合わせたサイドチェイン（ポンプ感）を共通で持ち、ジャンルごとに BPM・リズム・
ベース音色・コード進行・リード／パッドを丸ごと変えて差別化しています。

## 技術メモ

- メイン実装は `src/game/parts/*.js` です。`src/game.generated.js` は `npm run assemble` で生成されます。
- 3D 描画は Vite 経由で Three.js を読み込んでいます。
- 地形はプレイヤー周辺を動的生成する方式です。
- 重いチャンクメッシュ構築は `src/world-mesh-worker.js` で行い、メインスレッド側の `34-mesh-rebuild.js` が IndexedDB キャッシュの読み書きとフォールバックを担当します。ワーカーはCPUコア数に応じたプール（2〜6本）で並列に動き、`buildChunkState` は列単位のキャッシュ／スタックで高速化しています。完成メッシュはフレームあたりの時間予算内で順に反映し、生成中もカクつきにくくしています。
- ブロック表示は種類ごとに `InstancedMesh` を使っています。
- ブロック破壊/設置はレイキャストで判定しています。
- RAVE/音楽会場関連の主な実装は `src/game/parts/60-rave-venues.js` と `src/game/parts/70-music.js` です。
- 会場BGMの mp3 検出/再生は `70-music.js`、会場の形・拍同期・DJ操作は `60-rave-venues.js` が中心です。

- 文字化けしやすいので、README や表示文言を編集するときは UTF-8 として扱ってください。
- 未追跡フォルダ `gikopoi2/` と `hallucinate/` はこのプロジェクトの変更としては触らないでください。
- 会場を増やす場合は、`RAVE_KEY_BINDINGS`、`RAVE_VENUES`、`RAVE_FX`、`step***()` シーケンサー、会場生成ロジックをセットで更新してください。
- 音楽ジャンルを増やす場合は、既存曲の微変更ではなく、BPM、リズム、ベース音色、リード/パッド、コード進行、会場の形をまとめて変えると差が出ます。

## 確認コマンド

PowerShell で以下を実行すると、結合と本番ビルドをまとめて確認できます。

```powershell
npm.cmd run check
```

ローカルで確認する場合:

```powershell
npm.cmd run dev
```

その後、ブラウザで `http://127.0.0.1:5173/` を開きます。
