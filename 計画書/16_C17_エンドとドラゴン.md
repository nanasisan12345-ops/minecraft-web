【共通前提 — このプロジェクトの鉄則】
- リポジトリ: Vite + Three.js のボクセルゲーム。ソースは src/game/parts/*.js（番号順に結合され
  src/game.generated.js が生成される。生成物は絶対に手で編集しない。npm run assemble で再生成）。
- 関数宣言はモジュール全体でホイストされるためファイル番号をまたいだ呼び出しは可。ただし
  トップレベル実行時の変数参照は定義順（番号順）に注意。
- 検証コマンド: npm.cmd run check（assemble+vite build）。これが通ることは最低条件で、十分条件ではない。
  必ず npm.cmd run dev のプレビューを実ブラウザで開き、機能を操作して確認する。
  プレビュータブがバックグラウンドだと rAF がスロットルされ時間系が止まって見えるので、計測は
  フォアグラウンドで行う。window.__mcDbg（82-weather-and-loop.js 末尾）にテスト用フックが多数ある。
  新機能には必ず __mcDbg にテストフックを追加し、その使い方を成果報告に書くこと。
- ブロック追加の定番フロー: 20-textures.js にCanvasテクスチャ（+末尾normalMapリスト）→
  22-block-types.js に TYPES エントリと const → 53-inventory.js の ITEM_DEFS →
  55-crafting.js の RECIPES → 52-raycast.js（硬さ BLOCK_HARDNESS / 適正ツール blockPreferredTool /
  ツール制限 requiredToolTier / ドロップ blockDrops）。
- 非立方体形状は TYPES[type].model（{box:[x0,y0,z0,x1,y1,z1]} / {kind:'cross',...}）。
  当たり判定は collisionBoxes / collisionHeight。メッシュ描画はメインスレッド(34-mesh-rebuild.js)と
  Web Worker(src/world-mesh-worker.js)の両方に同じ結果が出るよう実装し、
  メッシュ出力が変わったら 34-mesh-rebuild.js の MESH_WORKER_VERSION を +1 する。
- ブロック編集の永続化は必ず setEdit() 経由（edits.set 直呼び禁止）。構造物生成は put/air 経由
  （world.set 直呼び禁止）。セーブは 33-save-state.js の統合 SAVE（mc_save_<seed>）。
  新フィールドは必ず「無ければデフォルト」で読み、既存セーブを壊さない。
- 【絶対禁止】60-rave-venues.js / 70-music.js（音楽会場）、music/、gikopoi2/、hallucinate/ の変更。

【今回のタスク C17】

【目的】ゲームクリアを実装する。エンダーアイ→地下要塞→エンドポータル→ドラゴン戦→クリア。

【対象ファイル】C16と同様のディメンション機構 / 39-hostile-mobs.js / 32-world-window.js /
53-inventory.js / 55-crafting.js / 59-progress.js / 新規UI(クリア画面)

【仕様】
1. エンダーアイ: パール+ブレイズパウダー(ロッド→パウダー2)。使用すると要塞方向へ飛んで消える
   (方向演出+効果音)。要塞は既存の地下遺跡ビルダーを拡張した「エンドポータル部屋つき要塞」を
   ワールドに数カ所生成(F6系のデバッグテレポートも追加)。
2. エンドポータル: 12個の枠にエンダーアイをはめる(要塞生成時に0-2個は既にはまっている)。
   完成で中央が黒い星空テクスチャのポータル化→乗るとエンドへ。
3. エンド地形: 浮島(エンドストーン)、黒曜石の柱6-10本、柱頂にエンドクリスタル(攻撃で爆発)。
   空は黒+星。帰りはドラゴン討伐後の帰還ポータルのみ。
4. ドラゴン戦: HP200。飛行パス(柱の外周旋回⇄中央ポータルへの急襲)。クリスタルが残っている間は
   近くのクリスタルからビームで回復(2/s)。攻撃=体当たり+ノックバック大。弓が主戦力になる調整。
   討伐でXP大量+ドラゴンの卵(記念ブロック)+帰還ポータル出現。
5. クリア画面: 討伐時に「終わりの詩」風の全画面テキスト(スキップ可)→オーバーワールドへ帰還。
   進捗(59-progress.js)に「エンドへ」「ドラゴン討伐」を追加。2周目はドラゴン不在でよい。

【受け入れ条件】
- アイで要塞を探し、ポータルを完成させ、エンドへ行き、クリスタルを割り、ドラゴンを倒し、
  クリア画面を見て、帰還する——全チェーンが通しでプレイ可能(実測必須)
- 死亡してもエンドポータルから再挑戦できる(進行が破綻しない)
- クリア後もワールドで遊び続けられる

【テスト方法】__mcDbg に goEnd()/dragonInfo() を追加。弱体化フック(HP10)で通し確認後、
本番HPでバランス確認。

【禁止事項】共通前提に同じ。シュルカー/エンドシティは実装しない。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- エンダーアイ: エンダーパール1+ブレイズパウダー1。右クリックで最寄りの要塞方向へ浮上しつつ
  飛んで消える(数秒後にその場にドロップ80% / 消滅20%)。
- 要塞: 地下深くに生成。ポータル部屋に12個の枠があり、各枠は10%の確率で最初からアイ入り。
  12個すべて埋めると起動し、中央3×3が「エンドポータル」(黒い星空テクスチャ)になる。
- エンド: エンドストーンの浮島 / 黒曜石の柱6〜10本(高さはばらばら) / 柱頂にエンドクリスタル
  (攻撃1回で爆発・威力6。近くにいると大ダメージ)。
- ドラゴン: HP200。行動パターン: 外周旋回(矢でしか届かない)→時々中央へ急降下体当たり
  (ダメージ10+特大ノックバック)→中央ポータル上でホバリング(このとき近接攻撃のチャンス)。
  クリスタルが1本でも残っていると毎秒2HP回復(クリスタルから回復ビームの演出)。
  つまり攻略手順は本家どおり「先に全クリスタルを壊す→ドラゴン本体」になる。
- 討伐: XP12000(オーブ分割で大量に散布) / 中央に帰還ポータル起動 / ドラゴンの卵(記念ブロック)。
  「終わりの詩」風スタッフロール(スキップ可)→オーバーワールドへ帰還。再訪時ドラゴンはいない。
