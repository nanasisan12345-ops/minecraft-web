【今回のタスク C13】

【目的】食料に本家の深み(調理で価値が上がる、隠し満腹度)を足す。

【対象ファイル】53-inventory.js / 55-crafting.js / 51-survival.js / 52-raycast.js

【仕様】
1. かまど精錬に食料を追加(SMELT_RESULT): 生牛肉→ステーキ(空腹8)、生豚肉→焼き豚(8)、
   生鶏肉→焼き鳥(6)、じゃがいも等は無いので対象外。既存の生肉 ITEM_DEFS の id を確認して接続。
2. 全食料に hunger と saturation を定義(ITEM_DEFS拡張)。saturation は隠し満腹度:
   食べると hidden ゲージ(最大=現在の空腹値)に加算され、空腹減少はまず hidden から引かれる。
   本家の簡略版でよい。リンゴ4/2.4、パン5/6、ステーキ8/12.8、ベリー2/0.4、牛乳は現状維持。
3. 金リンゴ: 金インゴット8+リンゴ。食べると空腹4+吸収HP4(上限20を超える一時HP、
   被弾で先に減る。HUDでは黄色ハートで区別)。
4. 空腹18以上で自然回復(C3と重複するなら整合)、空腹0で飢餓ダメージは既存仕様を維持。

【受け入れ条件】
- 生肉を焼くと回復量が上がる。ステーキを食べると長時間空腹が減らない(saturationの実感)
- 金リンゴで黄色ハートが付き、被弾で先に消える
- 旧セーブの食料アイテムがそのまま使える

【テスト方法】__mcDbg.survival()/give で各食料の hunger/saturation 遷移を数値確認。

【禁止事項】共通前提に同じ。状態異常システム(毒等)には踏み込まない。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- 食料表(空腹回復/隠し満腹度saturation)(本家準拠):
  リンゴ4/2.4 / パン5/6.0 / ステーキ8/12.8 / 焼き豚8/12.8 / 焼き鳥6/7.2 / 焼き羊肉6/9.6 /
  生牛肉3/1.8 / 生豚肉3/1.8 / 生鶏肉2/1.2 / 生羊肉2/1.2 / 腐肉4/0.8 / ベリー2/0.4 /
  金リンゴ4/9.6+吸収ハート4(2分)。
- saturationの上限は「現在の空腹値」。消耗はまずsaturationから減り、0になってから空腹が減る。
- 精錬時間は既存と同じ(1個10秒)。生肉はかまど燃料では焼けない…ではなく通常の精錬素材として扱う。
- 金リンゴ: 金インゴット8+リンゴ1(リンゴを中央に囲む)。吸収ハートは黄色で表示し、
  被弾時に通常HPより先に減り、2分で消える。
