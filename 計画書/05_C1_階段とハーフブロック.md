【今回のタスク C1】

【目的】本家の建築の基本である階段とハーフブロックを追加し、建築表現と移動導線を本家に近づける。

【対象ファイル】20-textures.js / 22-block-types.js / 53-inventory.js / 55-crafting.js /
52-raycast.js / 34-mesh-rebuild.js / src/world-mesh-worker.js / 50-player-physics.js（確認のみ）

【仕様】
1. 階段: オーク(板材)・丸石・石レンガの3素材 × 4向き = 12個のIDバリアント。既存ドアの
   IDバリアント方式（22-block-types.js の setDoorShape 参照）に倣う。形状は model 2箱
   （下半分フル + 上半分半奥行き）、collisionBoxes も同じ2箱。アイテムは素材ごとに1つ
   （oak_stairs / cobblestone_stairs / stone_brick_stairs）で、設置時にプレイヤーの視線方位から
   向きIDを決める（ドアの設置ロジック参照）。どの向きを壊しても素材の階段1個をドロップ。
2. ハーフブロック: 同3素材 × 上付き/下付き = 6ID。アイテムは素材ごと1つ。設置時、クリックした
   面が上面なら下付き、下面なら上付き、側面ならクリック位置の高さで判定（ヒット点のy小数 >= 0.5
   で上付き）。model/collisionBoxes は半箱。
3. レシピ: 階段=素材6個の階段形 ['M  ','MM ','MMM'] → 4個。ハーフ=素材3個 ['MMM'] → 6個。
   キーは素材ごと（PLANKS/COBBLESTONE/STONE_BRICK）。
4. 採掘: 硬さ・適正ツールは元素材と同じ。木系は斧、石系はツルハシ。
5. 既存の1.05ステップアップ物理で0.5段は自動で登れるはず。階段を2段並べて歩いて登れることを確認。

【受け入れ条件】
- 3素材の階段が視線に応じた向きで設置され、階段2連で段差2を歩いて登れる
- ハーフブロックが上付き/下付きを打ち分けられ、下付きハーフの上に立てる（高さ0.5）
- 全レシピが作業台で一致し、壊すと正しいアイテムがドロップ、リロード後も形状が復元される
- メッシュはワーカー経路とフォールバック経路で同一に見える（MESH_WORKER_VERSION を+1すること）

【テスト方法】
- __mcDbg に give('oak_stairs') 等で入手→4方位から設置してスクショ確認
- __mcDbg.tryRecipe で全6レシピの一致を確認
- セーブ→リロードで向きが保存されることを確認

【禁止事項】共通前提の禁止事項に加え、既存ドア/フェンスのID(50-73)の並びを変えないこと。
向きの座標メタデータ化に手を出さないこと（IDバリアント方式で完結させる）。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- 階段の設置(本家): 水平向きはプレイヤーの視線方位（プレイヤーから見て奥が高くなる向き）。
  クリックした面の下半分に置けば通常、上半分なら逆さ階段(天井向き)。
  逆さ階段まで実装するなら素材ごと8ID。工数が厳しければ通常4IDのみとし「逆さは未実装」と
  HANDOFFに明記。
- 硬さ: 木の階段/ハーフ=2.0(斧適正) / 丸石系=2.0(ツルハシ) / 石レンガ系=1.5(ツルハシ)。
- ハーフブロック(下付き)の上に立つと高さ+0.5。ハーフの上面には通常ブロックを設置できること。
- 同一セルに上下ハーフを重ねて完全ブロック化(二重スラブ)は実装しない(明記)。
- 角の自動接続(内曲がり/外曲がり階段)は実装しない(明記)。
