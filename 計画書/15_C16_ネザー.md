【共通前提 — このプロジェクトの鉄則】
- リポジトリ: Vite + Three.js のボクセルゲーム。ソースは src/game/parts/*.js（番号順に結合され
  src/game.generated.js が生成される。生成物は絶対に手で編集しない。npm run assemble で再生成）。
- 関数宣言はモジュール全体でホイストされるためファイル番号をまたいだ呼び出しは可。ただし
  トップレベル実行時の変数参照は定義順（番号順）に注意。
- 検証コマンド: npm.cmd run check（assemble+vite build）。これが通ることは最低条件で、十分条件ではない。
  必ず npm.cmd run dev のプレビューを実ブラウザで開き、機能を操作して確認する。
  プレビュータブがバックグラウンドだと rAF がスロットルされ時間系が止まって見えるので、計測は
  フォアグラウンドで行う。window.__mcDbg（82-weather-and-loop.js 末尾）にテスト用フックが多数ある。
  新機能には必ず __mcDbg にテストフックを追加し、その使い方を成果報告に書くこと。
- ブロック追加の定番フロー: 20-textures.js にCanvasテクスチャ（+末尾normalMapリスト）→
  22-block-types.js に TYPES エントリと const → 53-inventory.js の ITEM_DEFS →
  55-crafting.js の RECIPES → 52-raycast.js（硬さ BLOCK_HARDNESS / 適正ツール blockPreferredTool /
  ツール制限 requiredToolTier / ドロップ blockDrops）。
- 非立方体形状は TYPES[type].model（{box:[x0,y0,z0,x1,y1,z1]} / {kind:'cross',...}）。
  当たり判定は collisionBoxes / collisionHeight。メッシュ描画はメインスレッド(34-mesh-rebuild.js)と
  Web Worker(src/world-mesh-worker.js)の両方に同じ結果が出るよう実装し、
  メッシュ出力が変わったら 34-mesh-rebuild.js の MESH_WORKER_VERSION を +1 する。
- ブロック編集の永続化は必ず setEdit() 経由（edits.set 直呼び禁止）。構造物生成は put/air 経由
  （world.set 直呼び禁止）。セーブは 33-save-state.js の統合 SAVE（mc_save_<seed>）。
  新フィールドは必ず「無ければデフォルト」で読み、既存セーブを壊さない。
- 【絶対禁止】60-rave-venues.js / 70-music.js（音楽会場）、music/、gikopoi2/、hallucinate/ の変更。

  既存キーバインドを奪わない。npmパッケージの追加も禁止（three固定）。

【今回のタスク C16】

【目的】ゴールB の中核。黒曜石ポータル→ネザー地形→ブレイズ→醸造(ポーション)までの片道分。

【対象ファイル】32-world-window.js / 22-block-types.js / 20-textures.js / 39-hostile-mobs.js /
53-inventory.js / 55-crafting.js / 52-raycast.js / 33-save-state.js / 14-sky.js / 82-weather-and-loop.js /
新規 35-dimensions.js(番号は32-36の空きに合わせて調整可)

【仕様】
1. ポータル: 黒曜石の縦枠(内側2x3)を火打石と打ち金で着火→内側に紫のポータルブロック
   (発光・非solid・アニメテクスチャ)。枠の検証は着火時のみ。プレイヤーが2秒立つと転移
   (暗転フェード→座標変換 1/8 →ネザー側に帰還ポータルを自動生成)。
2. ディメンション切替: DIM='overworld'|'nether' のグローバル状態。地形関数(columnDesc/terrainBlockAt)
   をDIMで分岐し、チャンクキャッシュのキーとセーブのedits/liquidsキーに DIM を含める。
   切替時は regenWindow 全再生成+空/霧/BGM切替(赤黒い霧、天井付き地形なので空は見えない)。
   ネザー地形: y=0-127相当、ネザーラック主体、溶岩海(y<31)、グロウストーン天井、
   ソウルサンド帯(移動減速)、ネザー水晶鉱石(→ネザー水晶)。水は置けない(蒸発音)。
3. ネザー要塞(ミニ): 既存の構造物ビルダー方式でネザーレンガの回廊+塔をまばらに生成。
   ブレイズスポナー的な「湧き部屋」(部屋内は常時ブレイズ上限2)。宝箱。
4. ブレイズ: 浮遊+火の弾(スケルトンの矢AIを流用、着弾で炎上)。ドロップ=ブレイズロッド。
5. 醸造: 醸造台(ブレイズロッド+丸石3)。UI=水入り瓶3+素材1。瓶=ガラス3。
   ネザーウォート(要塞に生成、ソウルサンドに植えられる)→奇妙なポーション→
   ・+ブレイズパウダー=力(攻撃+3, 3分) ・+マグマクリーム省略 ・+火打石…簡略化:
   力/俊敏(速度+20%)/治癒(即時HP4)/耐火(溶岩無効2分)の4種でよい。効果は SURVIVAL に
   effects 配列を追加しHUDにアイコン+残り時間。
6. ゾンビピッグマン等は実装しない。ガストは任意(できれば: 浮遊+火球+泣き声)。

【受け入れ条件】
- ポータル築造→着火→転移→帰還の往復ができ、座標が1/8対応、リロード後も両側のポータルが残る
- ネザーで採掘/建築/戦闘が通常どおり動き、オーバーワールドのセーブと混ざらない
- ブレイズを倒してロッド入手→醸造台で耐火ポーション→溶岩を泳いで無事(実測)
- ネザーにいる間、オーバーワールドの液体シム/モブが止まっている(リソース分離)

【テスト方法】__mcDbg に dim()/goNether() を追加。往復・醸造・効果の全チェーンを実測しスクショ。

【禁止事項】共通前提に同じ。ワールドウィンドウ機構の複製(2世界同時保持)は禁止。切替方式で実装。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- ポータル: 黒曜石で内側2×3の枠(角は不要、最小10個)。火打石と打ち金で着火。
  中に立って4秒で転移(※本文の2秒は4秒に置き換え)。座標対応: ネザー座標=地上の1/8。
  ポータルブロックは光レベル11・紫パーティクル・独特の環境音。
- ネザー地形: ネザーラック(硬さ0.4・ツルハシで一瞬) / 溶岩海(下層) / ソウルサンド(移動40%減速+
  わずかに沈む) / グロウストーン(天井の房。壊すとダスト2-4、ダスト4→グロウストーンブロック) /
  ネザー水晶鉱石(鉄ツルハシ、XP2-5)。水は設置不可(蒸発の煙と音)。
  【本家の名物】ネザーでベッドを使うと爆発する(威力5、TNT超)。必ず入れること。
- 溶岩はネザー内では更新0.5秒・7ブロックまで流れる(C8の定数を切替)。
- ブレイズ: HP20 / 浮遊 / 火の弾3連射→クールダウン(弾: 直撃5+5秒炎上) / 溶岩・火ダメージ無効 /
  ドロップ=ブレイズロッド0-1(プレイヤー撃破時のみ)。
- ガスト(任意): HP10 / 大型・浮遊 / 火球は着弾で小爆発 / 泣き声の環境音。
- 醸造: 醸造台=ブレイズロッド1+丸石3 / ガラス瓶=ガラス3のV字→3本 / 1回で瓶3本同時、20秒 /
  燃料=ブレイズパウダー1で20回ぶん(簡略可) / 水入り瓶+ネザーウォート→奇妙なポーション →
  +ブレイズパウダー(ロッド1→2)=力(攻撃+3、3分) / +砂糖(サトウキビ1→1)=俊敏(+20%、3分) /
  +金インゴット=治癒(即時4HP)(本家はキラキラスイカだが未実装のため代用) /
  +ネザー水晶=耐火(2分)(本家はマグマクリームだが未実装のため代用)。
- ネザーウォート: ソウルサンドにのみ植えられる。4段階成長、骨粉無効。要塞内に初期生成。
