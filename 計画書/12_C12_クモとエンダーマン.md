【共通前提 — このプロジェクトの鉄則】
- リポジトリ: Vite + Three.js のボクセルゲーム。ソースは src/game/parts/*.js（番号順に結合され
  src/game.generated.js が生成される。生成物は絶対に手で編集しない。npm run assemble で再生成）。
- 関数宣言はモジュール全体でホイストされるためファイル番号をまたいだ呼び出しは可。ただし
  トップレベル実行時の変数参照は定義順（番号順）に注意。
- 検証コマンド: npm.cmd run check（assemble+vite build）。これが通ることは最低条件で、十分条件ではない。
  必ず npm.cmd run dev のプレビューを実ブラウザで開き、機能を操作して確認する。
  プレビュータブがバックグラウンドだと rAF がスロットルされ時間系が止まって見えるので、計測は
  フォアグラウンドで行う。window.__mcDbg（82-weather-and-loop.js 末尾）にテスト用フックが多数ある。
  新機能には必ず __mcDbg にテストフックを追加し、その使い方を成果報告に書くこと。
- ブロック追加の定番フロー: 20-textures.js にCanvasテクスチャ（+末尾normalMapリスト）→
  22-block-types.js に TYPES エントリと const → 53-inventory.js の ITEM_DEFS →
  55-crafting.js の RECIPES → 52-raycast.js（硬さ BLOCK_HARDNESS / 適正ツール blockPreferredTool /
  ツール制限 requiredToolTier / ドロップ blockDrops）。
- 非立方体形状は TYPES[type].model（{box:[x0,y0,z0,x1,y1,z1]} / {kind:'cross',...}）。
  当たり判定は collisionBoxes / collisionHeight。メッシュ描画はメインスレッド(34-mesh-rebuild.js)と
  Web Worker(src/world-mesh-worker.js)の両方に同じ結果が出るよう実装し、
  メッシュ出力が変わったら 34-mesh-rebuild.js の MESH_WORKER_VERSION を +1 する。
- ブロック編集の永続化は必ず setEdit() 経由（edits.set 直呼び禁止）。構造物生成は put/air 経由
  （world.set 直呼び禁止）。セーブは 33-save-state.js の統合 SAVE（mc_save_<seed>）。
  新フィールドは必ず「無ければデフォルト」で読み、既存セーブを壊さない。
- 【絶対禁止】60-rave-venues.js / 70-music.js（音楽会場）、music/、gikopoi2/、hallucinate/ の変更。

【今回のタスク C12】

【目的】本家の代表モブを追加し、素材チェーン(糸・革・骨粉・エンダーパール)を完成させる。

【対象ファイル】39-hostile-mobs.js / 37-animals.js / 53-inventory.js / 55-crafting.js / 48-farming.js

【仕様】
1. クモ: 平たい体+8脚の簡易モデル(makeCreeper等の箱組み方式)。光量7以下で湧き、
   明るい所では中立(攻撃されたら反撃)。壁登り: 進行方向が壁なら垂直速度+3で登る。
   HP16、攻撃2、ドロップ=糸0-2。弓レシピの繊維を糸に変更…は既存互換を壊すので、
   レシピは「繊維 or 糸」の両対応キーにする。
2. エンダーマン(簡易): 夜の地上に低確率で湧く。長身の黒い箱モデル+紫の目。
   視線カーソルを合わせて0.5秒で敵対(本家式)、敵対中は3-5秒ごとにプレイヤー周囲へテレポート
   (紫パーティクル+音)。水/雨でダメージを受けて中立に戻る。HP40、攻撃4、
   ドロップ=エンダーパール0-1(C17で使用)。パール投擲は実装しない(C17のエンダーアイ専用)。
3. ドロップ整合: 牛→革0-2追加。ゾンビ→腐肉(食べると空腹4回復+30%で空腹ペナルティ…
   状態異常が無いので「回復量が低い非常食」でよい)。スケルトン→骨0-2、骨→骨粉3。
   骨粉: 作物/苗木に右クリックで成長を1段階進める(48-farming.js の growCrops/growSaplings を流用)。
4. スポーン抽選への組み込みは既存の重み方式。上限・距離バランスは変えない。

【受け入れ条件】
- クモが壁を登って追ってくる。昼の明所では襲ってこない
- エンダーマンを見つめると敵対し、テレポートで背後に回られる。倒すとパールが出る
- 骨粉で小麦が即実る。革・腐肉・骨・糸が正しくドロップし、既存レシピが壊れていない

【テスト方法】__mcDbg.mobKinds に追加し直接スポーン→AI/ドロップ実測。骨粉は farmTest と組み合わせ。

【禁止事項】共通前提に同じ。既存モブのスポーンバランス定数を変えない。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- クモ: HP16 / 攻撃2 / 移動は歩行Mobの約1.3倍速 / 体型は平たい(高さ0.9・幅1.4の判定)。
  光レベル12以上では中立(攻撃されたら反撃)。壁登り可。
  ドロップ: 糸0-2 + 33%でクモの目(食料: 空腹2・低回復の非常食として扱う)。
- エンダーマン: HP40 / 攻撃7 / 高さ約2.9。プレイヤーのカーソルが頭部に合うと敵対(遠距離でも)。
  水・雨に触れると0.5秒ごとに1ダメージ+ランダムテレポート。テレポート範囲は32ブロック以内。
  ドロップ: エンダーパール0-1(C17で必須になるので、敵対させて倒せば確実に集まる調整に)。
- ドロップ追加: 牛/鹿=革0-2 / 羊=生羊肉1-2 / ゾンビ=腐肉0-2 / スケルトン=骨0-2+矢0-2。
- 骨粉: 骨1→骨粉3。小麦に使うと残り成長時間の40〜100%(ランダム)を短縮。苗木は45%で即成長判定。
  使用時に緑のキラキラパーティクル。
