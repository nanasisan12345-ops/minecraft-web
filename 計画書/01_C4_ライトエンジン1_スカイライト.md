【今回のタスク C4】

【目的】本家の見た目の核であるライトエンジンの第1段。空からの光(skylight 0-15)をチャンクごとに
計算し、メッシュ頂点カラーに焼き込む。これにより「洞窟や屋内が本当に暗い」世界にする。

【対象ファイル】src/world-mesh-worker.js / 34-mesh-rebuild.js / 22-block-types.js(mkMat) /
82-weather-and-loop.js / 12-lights.js（既存ライトの役割整理）

【仕様】
1. ワーカーの buildChunkState 後段に LightMap 計算を追加: 対象チャンク±1（パディング1チャンク、
   既存 collectMeshPayload の3x3範囲と同じ）で、各列の最上solid以上を15とし、下方向は透過ブロック
   （transparent/非solid。水は-3減衰）で15維持…ではなく本家式に「垂直は減衰なしで15、
   横方向伝播はBFSで距離1につき-1」。配列は Uint8Array(チャンク幅+2)^2×高さ を列スタック
   (columnStack)から構築。高さ方向は実ブロックのある範囲+マージンのみでよい（メモリ節約）。
2. メッシュ生成時、各面の頂点カラーとして「その面が接する空気側セルの light 値」を採用し、
   geometry に color attribute (3成分、light/15 の輝度) を追加。マテリアル側は
   mkMat に vertexColors: true を全ブロックで有効化。
3. メインスレッド側: 昼夜サイクルはこれまで通り環境光で表現するが、skylight の頂点カラーは
   「空がどれだけ届くか」の係数として働く（洞窟=0で常に暗い、地上=15で昼夜どおり）。
   82 の updateWeather/updateDayNight の環境光・ライト強度を再調整し、
   ・昼の地上は現状と同程度の明るさ
   ・洞窟(skylight 0, blocklightなし)はほぼ真っ暗（松明が必須になる暗さ、ただし完全な0ではなく0.03程度）
   になるようにする。夜の地上は skylight があっても暗い（環境光を下げる）。
4. 頂点カラーの最小値: このタスクの時点では blocklight が無いので、既存の PLACED_LIGHTS
   （プレイヤー設置の松明等の Three.js PointLight）はそのまま残す（C5で置換する）。
5. フォールバック経路（メインスレッドの同期ビルド）にも同じ計算を実装し、結果が一致すること。
6. MESH_WORKER_VERSION +1。パフォーマンス: 1チャンクのライト計算込みビルドが 60ms を超えないこと
   （現状37ms。BFSは荒く実装すると爆発するので、伝播は「空気セルかつ light>1」のみキュー投入）。

【受け入れ条件】
- 洞窟の奥が本当に暗く、入口からの光のグラデーションが見える（スクショ添付）
- 地上の昼の明るさ・夜の暗さが従来と同等以上の見栄え
- 家を建てて屋根を付けると屋内が暗くなり、窓から光が差す
- Node ベンチ（HANDOFF記載の bench.mjs 方式）で1チャンク60ms以内
- errors=0 / fallbacks=0、キャッシュ再訪問でも正しい明るさ

【テスト方法】__mcDbg に lightAt(x,y,z) フックを追加（ワーカーと同ロジックのデバッグ実装でよい）。
F4で洞窟へ→内部スクショ。地上に3x3x3の小屋を建て屋内の暗さを確認。

【禁止事項】共通前提に同じ。Three.js の PointLight/SpotLight を新たに追加しない。
チャンクあたりのフル3D配列(384高さ全部)を常時確保しない（メモリ）。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- 光レベルは0〜15の整数。輝度変換は本家近似: brightness(L) = 0.8^(15-L)（L15=1.0、L14=0.8、
  L0≈0.035）。完全な黒にはせず最低0.035程度のアンビエントを残す。
- スカイライト: 空に直通する列は15。不透明ブロックで0。水と葉は1ブロック通過ごとに-1、
  ガラス等その他の透過ブロックは減衰なし。横方向はBFSで1ブロックごとに-1。
- 夜: 月明かりにより地上の実効明るさは「光レベル4相当」が下限。夕暮れ/明け方は
  昼(15相当)⇄夜(4相当)を時間で補間する。
- 正しい見た目の基準: 昼でも窓のない部屋の中は真っ暗。窓を1つ開けると窓の周囲だけ
  グラデーションで明るくなる。洞窟は入口から奥へ15,14,13...と1ブロックずつ暗くなる。
