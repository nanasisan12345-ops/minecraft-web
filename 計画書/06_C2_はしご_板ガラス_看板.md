【共通前提 — このプロジェクトの鉄則】
- リポジトリ: Vite + Three.js のボクセルゲーム。ソースは src/game/parts/*.js（番号順に結合され
  src/game.generated.js が生成される。生成物は絶対に手で編集しない。npm run assemble で再生成）。
- 関数宣言はモジュール全体でホイストされるためファイル番号をまたいだ呼び出しは可。ただし
  トップレベル実行時の変数参照は定義順（番号順）に注意。
- 検証コマンド: npm.cmd run check（assemble+vite build）。これが通ることは最低条件で、十分条件ではない。
  必ず npm.cmd run dev のプレビューを実ブラウザで開き、機能を操作して確認する。
  プレビュータブがバックグラウンドだと rAF がスロットルされ時間系が止まって見えるので、計測は
  フォアグラウンドで行う。window.__mcDbg（82-weather-and-loop.js 末尾）にテスト用フックが多数ある。
  新機能には必ず __mcDbg にテストフックを追加し、その使い方を成果報告に書くこと。
- ブロック追加の定番フロー: 20-textures.js にCanvasテクスチャ（+末尾normalMapリスト）→
  22-block-types.js に TYPES エントリと const → 53-inventory.js の ITEM_DEFS →
  55-crafting.js の RECIPES → 52-raycast.js（硬さ BLOCK_HARDNESS / 適正ツール blockPreferredTool /
  ツール制限 requiredToolTier / ドロップ blockDrops）。
- 非立方体形状は TYPES[type].model（{box:[x0,y0,z0,x1,y1,z1]} / {kind:'cross',...}）。
  当たり判定は collisionBoxes / collisionHeight。メッシュ描画はメインスレッド(34-mesh-rebuild.js)と
  Web Worker(src/world-mesh-worker.js)の両方に同じ結果が出るよう実装し、
  メッシュ出力が変わったら 34-mesh-rebuild.js の MESH_WORKER_VERSION を +1 する。
- ブロック編集の永続化は必ず setEdit() 経由（edits.set 直呼び禁止）。構造物生成は put/air 経由
  （world.set 直呼び禁止）。セーブは 33-save-state.js の統合 SAVE（mc_save_<seed>）。
  新フィールドは必ず「無ければデフォルト」で読み、既存セーブを壊さない。
- 【絶対禁止】60-rave-venues.js / 70-music.js（音楽会場）、music/、gikopoi2/、hallucinate/ の変更。

【今回のタスク C2】

【目的】縦移動（はしご）と建築ディテール（板ガラス・文字が書ける看板）を追加する。

【対象ファイル】20-textures.js / 22-block-types.js / 53-inventory.js / 55-crafting.js /
52-raycast.js / 50-player-physics.js / 82-weather-and-loop.js / 33-save-state.js / index.html or styles.css

【仕様】
1. はしご: 4向きID（壁の4面に貼る薄板 model、厚さ0.125）。レシピ=棒7個のH字['S S','SSS','S S']→3個。
   設置は壁面クリック時のみ（対象面が側面のとき）。物理: プレイヤーAABBがはしごブロックと重なって
   いる間、重力を殺し、前進キーまたはジャンプで上昇(約2.4/s)、スニークで停止、下キーなしなら
   ゆっくり滑降(約1.5/s)。落下ダメージはしご接触でリセット。
2. 板ガラス: フェンスと同様の静的十字モデル（中央板2枚direction交差、厚さ0.125、collisionBoxes同形）。
   レシピ=ガラス6個['GGG','GGG']→16個。壊すと本家同様ドロップなし（ガラス同様）にするか迷う場合は
   ドロップなしを採用。
3. 看板: 立て看板のみ（既存 VILLAGE_SIGN の形状を流用可）。4向きID。レシピ=板材6+棒1→3個。
   設置直後にポインタを解放して小さな入力ダイアログ（1行×最大4行テキスト）を出し、確定で
   SAVE.signs["x,y,z"]=テキスト として保存。表示は CanvasTexture を板面に貼る（座標ごとに生成、
   dispose 管理）。壊すと看板アイテムをドロップしテキストを削除。右クリックで再編集。
4. 入力ダイアログは releasePointerForUi()/relockPointerForGame()（54-input.js）を使い、
   閉じたらポインタロックへ戻す。

【受け入れ条件】
- はしごで垂直の壁を登り降りでき、途中で手を離すとゆっくり滑り、着地で落下ダメージなし
- 板ガラスが窓として1ブロック厚未満に見える。フェンス同様の当たり判定
- 看板に日本語テキストを書き、表示され、リロード後も残り、再編集・破壊削除ができる
- MESH_WORKER_VERSION +1、全レシピ一致、console error/warn ゼロ

【テスト方法】__mcDbg.give で各アイテム入手→実操作。SAVE.signs の保存/復元を localStorage で確認。
はしご物理は高さ10の柱を作って登降とHP無変化を確認。

【禁止事項】共通前提に同じ。看板テキストのHTML挿入に注意（textContent/Canvas描画のみ、innerHTML禁止）。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- はしご: 登り2.35ブロック/秒、自然滑降は最大3.0ブロック/秒、スニーク中は完全停止。
  はしごに触れている間、落下距離は常にリセット。設置は「背面が不透明ブロックの側面」のみ。
  背面ブロックが壊されたら、はしごもアイテム化して落ちる。
- レシピ(本家): 棒7のH字 → はしご3 / ガラス6(横2段) → 板ガラス16 / 板材6+棒1 → 看板3。
- 看板: 4行×各15文字。設置直後に編集UI表示。壊すと看板1をドロップしテキスト削除。
- 板ガラス: 壊してもドロップなし(ガラス本体と同じ)。
