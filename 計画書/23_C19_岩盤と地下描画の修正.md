【今回のタスク C19】

【目的】地下に関する2つの重大バグを修正し、本家同様「Y=-64の岩盤まで掘れて、絶対に奈落へ落ちない」
世界にする。あわせて深層岩で地下の見た目を本家に寄せる。

【現象と原因（調査済み）】
A. マップ外落下: 最下層(Y=-64)がただの石で掘り抜けてしまう。岩盤(BEDROCK)ブロックが存在しない。
   32-world-window.js の oreTypeAt (y <= CHUNK_Y_MIN+1 で STONE を返す) と、ワーカー側の同等箇所。
B. 「地下が消える」見た目: 列のメッシュ走査範囲 columnYRange の
   naturalMin = Math.max(CHUNK_Y_MIN, Math.min(h, SEA) - 24)（32-world-window.js 付近、
   ワーカー world-mesh-worker.js の同名ロジックも同じ）が浅すぎ、海面-24より深い洞窟・
   採掘坑の壁や床のメッシュが生成されない。地形データ自体は Y=-64 まで存在する。

【対象ファイル】32-world-window.js / src/world-mesh-worker.js / 20-textures.js / 22-block-types.js /
52-raycast.js / 39-hostile-mobs.js(爆発) / 34-mesh-rebuild.js(バージョン更新)

【仕様】
1. 岩盤(BEDROCK)ブロックを追加:
   - Y=-64 は全列で必ず岩盤。Y=-63〜-60 は座標の決定的ハッシュで岩盤/石を混在させ、
     深いほど岩盤率を上げる(本家の岩盤グラデーション。-63≈80%、-62≈60%、-61≈40%、-60≈20%)。
   - terrainBlockAt(メイン)と terrainBlockAtCol(ワーカー)の両方に同一ロジックで実装し、
     必ず同じ座標で同じ結果になること(ハッシュは既存の hash2/hash3 系を使用)。
   - 破壊不可: BLOCK_HARDNESS を無限扱いにし、採掘ゲージが一切進まない(finishBreak に到達しない)。
     ドロップなし、ITEM_DEFS に登録しない(noAutoItem)、インベントリに入らない。
   - 爆発耐性: explodeAt(39-hostile-mobs.js)の破壊対象から除外(水/溶岩と同様の除外リストへ)。
   - 洞窟・地下湖・峡谷・構造物の生成が岩盤層(Y<=-60)を削らないこと(isCaveAt は既に
     CHUNK_Y_MIN+4 で止まっているので確認のみ。構造物系ビルダーが深すぎる場所を掘る場合はクランプ)。
2. メッシュ走査範囲の修正(バグBの本修正):
   - columnYRange(メイン)とワーカーの同等ロジックの naturalMin を、洞窟が生成されうる
     最深部までカバーする値に変更する(isCaveAt の下限は CHUNK_Y_MIN+4 なので、
     naturalMin = CHUNK_Y_MIN が最も単純で確実)。
   - 【性能の絶対条件】列スタック走査が「実ブロックのある範囲だけを見る」既存最適化を保つこと。
     単純に全列を-64〜319まで毎回走査すると1チャンクのビルド時間が悪化する。
     推奨実装: 列スタック(columnStack)構築時、地表から下へ「石が連続していて洞窟の可能性がない
     領域」を判定できるなら圧縮してよいが、迷ったらまず naturalMin=CHUNK_Y_MIN で実装し、
     Nodeベンチ(HANDOFF記載の bench.mjs 方式)で1チャンク60ms以内なら良しとする。
     60msを超えたら「洞窟領域ノイズ(caveRegion)が負の列は地下走査を浅く打ち切る」等の
     列単位スキップを入れる。
   - 修正後、深い洞窟(F9の地下湖、F6の地下遺跡、F8の廃坑)の壁・床・天井が欠けなく描画されること。
3. 深層岩(DEEPSLATE)を追加(見た目の本家寄せ):
   - y < 0 の石を深層岩に差し替える(y=0〜8 はハッシュで石/深層岩を混在させる遷移帯)。
   - テクスチャは石より暗いグレー+縦筋。硬さ3.0(石の2倍)、ツルハシ適正、ドロップは深層岩
     そのもの(本家は深層岩の丸石だがアイテム増加を避けるため簡略。HANDOFFに簡略と明記)。
   - 鉱石は既存の鉱石ブロックのままでよい(深層岩鉱石バリアントは作らない。簡略と明記)。
   - 深層岩は精錬不可でよい。建材として設置可能。
4. 奈落の保険: 岩盤により通常プレイでは落ちなくなるが、既存の奈落死判定
   (82-weather-and-loop.js: y < CHUNK_Y_MIN - 40 で即死)はそのまま残す。
5. MESH_WORKER_VERSION を +1(地形出力が変わるため。IndexedDBキャッシュの世代分離)。

【受け入れ条件】
- 新規ワールドで真下掘り→Y=-64で岩盤に到達し、左クリック長押しでも採掘ゲージが進まず壊せない
- Y=-63〜-60に岩盤と石(深層岩)が混在し、隙間を縫って掘っても最終的に必ずY=-64の岩盤で止まる
- TNT・クリーパー爆発で岩盤が壊れない
- 深さY=-30以深の洞窟・地下遺跡・廃坑・地下湖で、壁・床・天井のメッシュが欠けない(修正前は
  海面-24以深が描画されなかった。F6/F8/F9で移動して確認、スクショ添付)
- y<0が深層岩の見た目になり、石より掘るのに時間がかかる
- Nodeベンチで1チャンクのビルド時間60ms以内、初期ロードが現状(数秒)から体感悪化しない
- 旧セーブが正常に読める。MESH_WORKER_VERSION更新によりキャッシュが再生成される(エラーなし)
- console error/warn ゼロ

【テスト方法】
- __mcDbg に digToBedrock() 的なフック(プレイヤー直下をY=-64まで掘って現在Yと最下ブロック名を
  返す)を追加して実測。既存の F3 飛行+F6/F8/F9 テレポートで深部の描画を目視+スクショ。
- ベンチ: HANDOFF記載の bench.mjs 方式で修正前後の1チャンク時間を比較して報告。
- explodeAt はデバッグフック __mcDbg.explode で岩盤の隣を爆破して耐性確認。

【禁止事項】共通前提の禁止事項に同じ。加えて:
- 岩盤に requiredToolTier 方式(壊せるが落ちない)を使わない。「そもそも壊せない」が本家仕様。
- CHUNK_Y_MIN/CHUNK_Y_MAX の値自体を変えない(ワールド範囲は現状維持)。
- 性能最適化(列キャッシュ/列スタック/ワーカープール)の既存構造を壊さない。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- 岩盤: Y=-64が完全な岩盤層。Y=-63〜-60はランダム混在で上に行くほど減る(本家1.18以降)。
  サバイバルでは破壊・設置・爆破いずれも不可能。
- 深層岩: Y=0以深が深層岩帯、Y=0〜8が石との遷移帯。硬さ3.0(石1.5の2倍)。ツルハシ適正。
- 本家に「マップ外への落下」はオーバーワールドには存在しない(岩盤で必ず止まる)。
  奈落ダメージはY=-64より下に出た場合のみ(通常は不可能)。
