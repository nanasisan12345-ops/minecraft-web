【共通前提 — このプロジェクトの鉄則】
- リポジトリ: Vite + Three.js のボクセルゲーム。ソースは src/game/parts/*.js（番号順に結合され
  src/game.generated.js が生成される。生成物は絶対に手で編集しない。npm run assemble で再生成）。
- 関数宣言はモジュール全体でホイストされるためファイル番号をまたいだ呼び出しは可。ただし
  トップレベル実行時の変数参照は定義順（番号順）に注意。
- 検証コマンド: npm.cmd run check（assemble+vite build）。これが通ることは最低条件で、十分条件ではない。
  必ず npm.cmd run dev のプレビューを実ブラウザで開き、機能を操作して確認する。
  プレビュータブがバックグラウンドだと rAF がスロットルされ時間系が止まって見えるので、計測は
  フォアグラウンドで行う。window.__mcDbg（82-weather-and-loop.js 末尾）にテスト用フックが多数ある。
  新機能には必ず __mcDbg にテストフックを追加し、その使い方を成果報告に書くこと。
- ブロック追加の定番フロー: 20-textures.js にCanvasテクスチャ（+末尾normalMapリスト）→
  22-block-types.js に TYPES エントリと const → 53-inventory.js の ITEM_DEFS →
  55-crafting.js の RECIPES → 52-raycast.js（硬さ BLOCK_HARDNESS / 適正ツール blockPreferredTool /
  ツール制限 requiredToolTier / ドロップ blockDrops）。
- 非立方体形状は TYPES[type].model（{box:[x0,y0,z0,x1,y1,z1]} / {kind:'cross',...}）。
  当たり判定は collisionBoxes / collisionHeight。メッシュ描画はメインスレッド(34-mesh-rebuild.js)と
  Web Worker(src/world-mesh-worker.js)の両方に同じ結果が出るよう実装し、
  メッシュ出力が変わったら 34-mesh-rebuild.js の MESH_WORKER_VERSION を +1 する。
- ブロック編集の永続化は必ず setEdit() 経由（edits.set 直呼び禁止）。構造物生成は put/air 経由
  （world.set 直呼び禁止）。セーブは 33-save-state.js の統合 SAVE（mc_save_<seed>）。
  新フィールドは必ず「無ければデフォルト」で読み、既存セーブを壊さない。
- 【絶対禁止】60-rave-venues.js / 70-music.js（音楽会場）、music/、gikopoi2/、hallucinate/ の変更。
  英字キー R T Y U I O P [ Z X C V J K L M（会場中のみのものを含む）と N, G, F3-F11, 0 の
  既存キーバインドを奪わない。npmパッケージの追加も禁止（three固定）。

【今回のタスク C10】

【目的】本家の成長リソースであるXPを導入し、あわせてネザーへの道具(黒曜石採掘・着火)を揃える。

【対象ファイル】39-hostile-mobs.js / 41-item-drops.js(参考) / 51-survival.js / 52-raycast.js /
53-inventory.js / 55-crafting.js / 20-textures.js / 22-block-types.js / 33-save-state.js / HUD(styles.css)

【仕様】
1. XPオーブ: 新エンティティ(小さな緑発光スプライト、既存 ITEM_DROPS の実装を雛形に別リスト XP_ORBS)。
   吸引半径2.4/取得1.1は同じ。取得で xp 加算+チン音。
2. 取得源: 敵討伐(ゾンビ/スケルトン/クリーパー5、スライム2-4)、鉱石採掘(石炭1-2、ダイヤ/金3-7、
   ※シルクタッチ無いので常時)、精錬取り出し(0.5-1相当を蓄積)、繁殖1-3。
3. レベル: 本家式の必要量テーブル(Lv0-15: 2L+7 …)を簡略化してよいが単調増加にする。
   HUDにレベル数字+緑バー(ホットバー直上)。SAVE.xp {level, points} を保存。
4. 死亡時: XPは失わない(このゲームはユーザー方針で「キープインベントリ」= 死んでもアイテム・XPを
   ロストしない。51-survival.js の diePlayer 参照。本家の死亡ロストは実装しないこと)。
5. 黒曜石: 新ブロック(硬さ大、ダイヤツルハシ必須 requiredToolTier=4、採掘10秒級)。C8の生成に加え
   地形の溶岩湖表面にも露出させられれば尚可(任意)。
6. 火打石と打ち金: レシピ=鉄インゴット+火打石(火打石はC14の砂利から。C14未実装の間は
   ITEM_DEFS に火打石を先行追加し、砂利ドロップは後続タスクで接続)。使うと対象面に炎…は
   実装コストが高いので「TNT着火」「ネザーポータル着火(C16)」「敵への着火」専用でよい。耐久65。

【受け入れ条件】
- 敵を倒す/鉱石を掘るとオーブが飛び散り、吸い寄せられ、バーが伸びてレベルアップ音が鳴る
- 死亡してもレベル/ポイントが減らない。リロードでレベル/ポイント復元
- 黒曜石がダイヤツルハシでのみ回収できる(鉄では壊せてもドロップしない)
- 火打石と打ち金でTNTに着火できる

【テスト方法】__mcDbg に xp()/giveXp(n) を追加。討伐/採掘/精錬/死亡の各経路を実測。

【禁止事項】共通前提に同じ。エンチャント(C11)には踏み込まない。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- レベル必要XP(本家式): Lv0-15: 2×Lv+7 / Lv16-30: 5×Lv-38 / Lv31+: 9×Lv-158。
- 採掘XP: 石炭鉱石1-2 / ダイヤ鉱石3-7 / レッドストーン鉱石1-5(C15) / ネザー水晶2-5(C16)。
  鉄・金鉱石は採掘では0(精錬時に入る)。ブロック設置→再採掘でXPが無限に出ないよう、
  プレイヤーが設置したブロック(edits)からはXPを出さない。
- 精錬XP(取り出し時に個数ぶん): 鉄0.7 / 金1.0 / 食料0.35 / 丸石→石0.1 / 砂→ガラス0.1。
  端数は内部で蓄積し、整数になったぶんをオーブ化。
- 討伐XP: ゾンビ/スケルトン/クリーパー/クモ=5 / スライム大4・中2・小1 / エンダーマン5 /
  ブレイズ10。繁殖成立で1-7。
- 死亡時: 本家は「7×レベル(上限100)を散布して残り消滅」だが、このゲームは**キープインベントリ方針
  (死んでもアイテム・XPをロストしない)**のため死亡ロストは実装しない(2026-07-12 ユーザー決定)。
- 黒曜石: 硬さ50。ダイヤツルハシで約9.4秒。ダイヤ未満では壊せてもドロップしない。
- 火打石と打ち金: 鉄インゴット1+火打石1、耐久64。
