【今回のタスク C8】

【目的】静的な液体を本家式の「流れる液体」にする。バケツ・地形の水・溶岩すべてが対象。

【対象ファイル】22-block-types.js / 32-world-window.js / 52-raycast.js / 34-mesh-rebuild.js /
src/world-mesh-worker.js / 82-weather-and-loop.js / 33-save-state.js / 51-survival.js

【仕様】
1. 液体表現: WATER/LAVA を「ソース」とし、流水はレベル1-7を別ID帯 or レベル配列で表現する。
   推奨実装: 新Map `liquids`（"x,y,z" -> {type:'water'|'lava', level:0-7}）+ チャンク索引。
   level 0 = ソース。メッシュはレベルに応じて上面の高さを (8-level)/9 に下げる
   （ワーカーへ liquids を payload で渡す。フォールバック経路も同様）。
2. シミュレーション: 更新キュー方式。液体セルの設置/破壊/隣接変化でキューに積み、
   tick(水=0.25s間隔, 溶岩=1.0s間隔)ごとに処理:
   - 下が空気なら下へ流れる(下は level 1 の落下水)。下が塞がれていれば水平4方向へ level+1 で拡散
     (水は最大7、溶岩は最大4)。
   - 供給元が消えたら再計算して枯れる(隣接の level-1 供給が無ければ自分も消える)。
   - 無限水源: 水ソースが水平に2つ隣接する空気セル(下が solid)はソース化。
   - 水×溶岩: 溶岩ソース+水接触=黒曜石、流溶岩+水=丸石。石化時に「ジュッ」音(44-sound-effects.js)。
3. 地形生成の海/川/湖の水は従来どおり暗黙ブロックでよい(全部をシムに載せない)。シム対象は
   「プレイヤーが置いた液体」「採掘等で隣接が変化した液体」だけに限定する(性能維持のため)。
   セーブ: liquids を SAVE に保存(ソースのみ保存し、流水はロード時に再シムでよい)。
4. 溶岩接触ダメージ・炎上(2秒)を追加。水に入ると炎上解除。
5. プレイヤー/アイテムドロップは流れに押される(レベル勾配から流向ベクトルを計算、軽く加速)。

【受け入れ条件】
- バケツで置いた水が階段状に7ブロック広がり、崖で滝になる。汲む/塞ぐと枯れる
- 2x2の穴に水2つで無限水源ができる
- 溶岩に水をかけると黒曜石/丸石ができる。溶岩で炎上し、水で消える
- 放置してもFPSが落ちない(アイドル時はキュー空でコスト0であることを確認)
- セーブ→リロードで水地形が復元される

【テスト方法】__mcDbg に liquidInfo(x,y,z)/simStats() を追加。滝・無限水源・黒曜石生成を実測。
性能は5分放置でフレーム時間が変わらないこと。

【禁止事項】共通前提に同じ。毎フレーム全液体走査の実装は禁止(必ずイベント駆動キュー)。
自然地形の海・川を初期状態で全部シムに載せない。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- 水: 更新間隔0.25秒。平地で水源から7ブロックまで(レベル1〜7)。
- 溶岩(地上世界): 更新1.5秒。3ブロックまでしか流れない(レベルが2ずつ減る)。
  ネザー内では更新0.5秒・7ブロック(C16で切替)。
- 流れ先の選択(本家の重要挙動): 水平拡散の際、4ブロック以内に「下へ落ちられる穴」があれば
  その方向へ優先して流れる(これで水路が作れる)。実装が困難なら全方向拡散でも可だが、
  可能な限り実装する。
- 変換則: 溶岩[源]に水が触れる → 黒曜石 / 溶岩[流れ]に水が触れる → 丸石 /
  水[源]の上に溶岩が流れ込む → 石。
- 無限水源: 同じ高さの水源2つと水平に隣接し、下がsolidまたは水源のセルは水源になる。
- バケツで汲めるのは[源]のみ。[流れ]は汲めない。
- アイテムドロップは水に浮き、プレイヤー/Mob/アイテムは流れ方向に約1.4/sで押される。
