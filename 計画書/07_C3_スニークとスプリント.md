【共通前提 — このプロジェクトの鉄則】
- リポジトリ: Vite + Three.js のボクセルゲーム。ソースは src/game/parts/*.js（番号順に結合され

- 関数宣言はモジュール全体でホイストされるためファイル番号をまたいだ呼び出しは可。ただし
  トップレベル実行時の変数参照は定義順（番号順）に注意。
- 検証コマンド: npm.cmd run check（assemble+vite build）。これが通ることは最低条件で、十分条件ではない。
  必ず npm.cmd run dev のプレビューを実ブラウザで開き、機能を操作して確認する。
  プレビュータブがバックグラウンドだと rAF がスロットルされ時間系が止まって見えるので、計測は
  フォアグラウンドで行う。window.__mcDbg（82-weather-and-loop.js 末尾）にテスト用フックが多数ある。

- ブロック追加の定番フロー: 20-textures.js にCanvasテクスチャ（+末尾normalMapリスト）→

  ツール制限 requiredToolTier / ドロップ blockDrops）。
- 非立方体形状は TYPES[type].model（{box:[x0,y0,z0,x1,y1,z1]} / {kind:'cross',...}）。

【今回のタスク C3】

【目的】本家の移動の手触り（スニークで縁から落ちない、スプリントで視野が広がり空腹が減る）を再現する。

【対象ファイル】50-player-physics.js / 54-input.js / 51-survival.js / 82-weather-and-loop.js（ループ配線）

【仕様】
1. スニーク: ShiftLeft 押下中、速度 1.31/s、目線を0.15下げ、【重要】onGround かつスニーク中は
   移動後の足元にブロックが無くなる移動を打ち消す（本家の「縁で止まる」挙動）。moveAxis で
   移動先の (x,z) 直下1.0以内に衝突ボックスが無ければその軸移動をキャンセルする実装でよい。
2. スプリント: W ダブルタップ（0.3秒以内）または Ctrl+W で開始。前進が途切れる/空腹が6以下で解除。
   速度は既存 SPRINT 定数を使用。スプリント中は camera.fov を +10 へ 0.15秒でイージング（解除で戻す。
   camera.updateProjectionMatrix() を忘れない）。空腹消費: スプリント100mごと相当で0.5、
   ジャンプ・採掘・戦闘にも微小な消費を追加（詳細な数値はコード内定数にまとめ調整可能に）。
3. 空腹回復: 空腹18以上でHPが2秒ごとに0.5自然回復（既存仕様と重複するなら整合させる）。
4. Shift はインベントリの Shiftクリック（一括移動）と競合しないこと（コンテナ開時は移動系を止める
   既存ガードを確認）。

【受け入れ条件】
- スニークで1ブロックの縁を歩いても落ちない。スニーク解除で落ちる
- Wダブルタップでスプリント開始、FOVが滑らかに広がる、空腹が徐々に減る、空腹6以下で走れない
- 既存の会場ダンスキー(Z/X/C/V)や設定キーと競合しない

【テスト方法】高さ5の柱の上でスニーク移動テスト。__mcDbg に survival() で空腹値を監視しつつ
スプリント。fov の値を preview の javascript 評価で確認。

【禁止事項】共通前提に同じ。WALK/SPRINT/GRAVITY/JUMP の既存定数値を変えない（手触り回帰防止）。

【本家準拠 数値リファレンス — 上の本文と数値が食い違う場合はこちらを優先する】

- 本家の速度: 歩行4.317/s、スニーク=歩行の30%(1.295/s)、スプリント=歩行の1.3倍(5.612/s)。
  ※当ゲームは既存 WALK/SPRINT 定数を維持する方針のため、スニークは WALK×0.30 で計算する。
- スニーク: 目線を約0.3下げる。onGround中、移動先の足元(直下1.0以内)に支えがない水平移動は
  打ち消す(縁から落ちない)。
- スプリント: FOV×1.15。空腹6(ゲージ3個)以下では開始できない。
- 消耗(exhaustion)システム(本家準拠): 内部値が4.0に達するたびリセットし、
  saturation>0ならsaturation-1、なければ空腹-1。
  加算表: スプリント0.1/m / ジャンプ0.05 / スプリントジャンプ0.2 / 攻撃命中0.1 /
  被ダメージ0.1 / ブロック破壊0.005 / 水泳0.01/m / 自然回復1HPごとに6.0。
- 自然回復: 空腹18以上で4秒ごとに1HP。空腹20かつsaturation>0なら0.5秒ごとに1HP(高速回復)。
- 飢餓: 空腹0で4秒ごとに1ダメージ、HP1で停止(本家ノーマル難易度準拠。餓死はしない)。
